# Forge GitHub Plugin

`forge-github` is an official task plugin for the Forge workflow orchestration platform. It provides task types for interacting with the GitHub REST API.

---

## Features

- `github.create_issue`: Creates an issue on GitHub with title, body, and labels.
- Automatic entry point discovery under `forge.plugins`.

---

## Installation

```bash
pip install forge-github
```
